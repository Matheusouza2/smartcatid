# 🐱 SmartCatID

O **SmartCatID** é um projeto de reconhecimento facial voltado para **identificação de gatos**, utilizando técnicas de **Visão Computacional** e **Machine Learning**.  
O objetivo é permitir a captura de imagens via dispositivo móvel e realizar a detecção e identificação facial de felinos de forma automatizada.

O projeto é desenvolvido com **Expo / React Native**, integrando bibliotecas nativas para acesso à câmera e processamento de imagem.

---

## Pré-requisitos

Antes de executar o projeto, certifique-se de ter instalado:

- **Node.js** (versão LTS recomendada)
- **npm** ou **yarn**
- **Expo CLI**
- **Android Studio** (para Android) ou **Xcode** (para iOS)
- Dispositivo físico ou emulador configurado

Para instalar o Expo CLI globalmente:

```bash
npm install -g expo-cli
```

## Instalação do projeto

```bash
git clone https://github.com/Matheusouza2/smartcatid.git
cd smartcatid
npm install
```

## Executando o projeto

```bash
npx expo prebuild --clean
npx expo run:android
```

OU

```bash
npx expo prebuild --clean
npx expo run:ios
```
